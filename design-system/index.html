Four grounds, one accent, three families

The whole system, and what happens when you break it.

Every token below is read out of tokens.css by the same gate that fails the build, and every ratio is the one it measured. 55 pairings are gated and 9 are measured without being held to anything.

A design system you can only read is a brochure. This one you can take apart: turn System Mode on and every token here gets a slider, the page repaints as you drag, and the table underneath recomputes what each pairing measures against what it is held to.

It runs the arithmetic out of the same file the build does, so a number that goes red here is a number that fails CI. Nothing on this page is a simulation of the gate.

The old explorer kept its own copy of the token names in a TypeScript file, so changing a token left it describing a system that had moved on without it.

Type

Three families, and the fourth is whatever you already have.

Bricolage Grotesque carries every piece of display type and was drawn on its optical sizing. Instrument Sans carries the body. Caveat is the margin notes and nothing else. The mono is your system's own, because the spec strips are eleven-pixel labels and a webfont for them cost 78 kB on the critical path, which is more than the body and the display faces put together buy you.

The scale, as declared. Headlines carry text-wrap: balance and body copy carries pretty.
